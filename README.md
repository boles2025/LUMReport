# 🎓 نظام إحصائيات الطلاب الجامعي المتكامل - University Dashboard 2.0

نظام إحصائيات ومتابعة احترافي للطلاب (عربي RTL) مبني بـ **HTML5 + CSS3 + Vanilla JS + Bootstrap 5.3 RTL + Firebase** بدون أي Framework خارجي أو متطلبات بناء.

---

## 🌟 مميزات النظام الشاملة

### 📊 1. لوحة إحصائيات المستخدم (`index.html`)
- **تبويب الملخص العام (Overview)**:
  - 4 كروت إحصائية سريعة (KPIs): إجمالي التقديمات اليومية، سحب الجدد، سحب القدامى، **صافي الطلاب المقبولين الفعلي**، ومعدل السحب العام.
  - **جدول المقارنة الشامل**: يعرض لكل كلية (المتقدمين | سحب الجدد | سحب القدامى | إجمالي السحب | الصافي الفعلي | نسبة الإقبال % مع شريط تقدم).
  - **رسم بياني مجمّع**: مقارنة بصرية بين المتقدمين وإجمالي السحب لكل كلية.
- **تبويبات تفصيلية**: التقديمات اليومية، الكليات والأقسام، سحب الجدد، وسحب القدامى مع رسوم بيانية (Bar / Doughnut).
- **المزامنة الحية (Live Realtime Sync)**: تحديث فوري مباشر للوحة العرض عند قيام الأدمن بحفظ أي أرقام بدون الحاجة لإعادة تحميل الصفحة.
- **تصدير وطباعة**:
  - تصدير التقرير كاملاً إلى **Excel (CSV مع UTF-8 BOM)** لفتح ملفات الإكسيل باللغة العربية بدقة.
  - **زر طباعة منسق A4**: طباعة تقارير رسمية نظيفة مع ترويسة الجامعة وإخفاء الأزرار وأشرطة التحكم تلقائياً.

---

### 🛡️ 2. لوحة تحكم المسؤول الكاملة (`admin.html`)
- **لوحة القيادة والملخص (Admin Dashboard)**: شاشة شاملة تعرض الإجماليات والصافي وجدول الملخص السريع.
- **حفظ كل الأقسام بضغطة زر واحدة (Save All)**: حفظ التقديمات، الأقسام، سحب الجدد، وسحب القدامى دفعة واحدة.
- **نسخ بيانات من تاريخ سابق (Copy from Date)**: استيراد أرقام يوم سابق بضغطة زر لتعديل الفروقات اليومية فقط.
- **النسخ الاحتياطي والاستعادة الكاملة (Backup & Restore JSON)**: تنزيل نسخة احتياطية لكافة بيانات قاعدة البيانات واستعادتها في أي وقت.
- **حذف وتصفير البيانات**: تصفير الحقول أو حذف إحصائيات يوم محدد مع نوافذ تأكيد آمنة.
- **سرعة الإدخال عبر لوحة المفاتيح**: التنقل التلقائي بين حقول الإدخال بمفتاح `Enter` وتحديد النص تلقائياً عند التركيز.
- **حساب فوري مباشر**: حساب إجماليات الكليات والصافي أثناء الكتابة بدون انتظار.

## 🚀 طريقة التشغيل السريع

### عبر المتصفح أو Live Server
1. افتح مجلد المشروع في **VS Code** أو أي محرر.
2. انقر بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server** (أو افتح `index.html` في أي متصفح).
3. للوصول إلى لوحة الأدمن، افتح `admin.html` أو اضغط زر **دخول الأدمن**.

### الرفع على الاستضافة (Deployment)
يمكنك رفع مجلد المشروع مباشرة كما هو إلى أي استضافة مجانية:
- **Firebase Hosting**
- **GitHub Pages**
- **Vercel / Netlify**

## ⚙️ إعداد وقواعد Firebase

المشروع مُهيأ مسبقاً في `js/firebase.js`. بعد إنشاء مشروعك في [Firebase Console](https://console.firebase.google.com)، ضع القواعد التالية في **Realtime Database → Rules**:

```json
{
  "rules": {
    "statistics": {
      ".read": true,
      ".write": "auth != null"
    },
    "dailyApplications": {
      ".read": true,
      ".write": "auth != null"
    },
    "departments": {
      ".read": true,
      ".write": "auth != null"
    },
    "newStudentsWithdrawal": {
      ".read": true,
      ".write": "auth != null"
    },
    "oldStudentsWithdrawal": {
      ".read": true,
      ".write": "auth != null"
    }
  }
}
```
